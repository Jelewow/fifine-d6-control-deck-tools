# Микрофон Windows для FIFINE D6

Кнопка переключает системный мут микрофона, выбранного по умолчанию в **Параметры → Система → Звук → Ввод**. Это влияет на приложения, которые используют этот вход в общем режиме Windows.

- **ВКЛ** с зелёным микрофоном означает, что системный мут снят.
- **МУТ** с красным перечёркнутым микрофоном означает, что вход заглушён.
- **Н/Д** означает, что состояние входа сейчас недоступно.

Кнопка обновляется при появлении на панели, после нажатия и в течение примерно полусекунды после изменения системного мута или переключения входа по умолчанию. Аппаратный мут на корпусе микрофона отображается, если драйвер передаёт его состояние Windows. [Windows Core Audio](https://learn.microsoft.com/en-us/windows/win32/api/endpointvolume/nn-endpointvolume-iaudioendpointvolume)

## Установка

Понадобятся Windows 10 или 11 и FIFINE Control Deck версии 3.10.201.0506 или новее.

1. Полностью выйди из FIFINE Control Deck через значок приложения в трее.
2. Распакуй архив и скопируй папку `local.fifine.micmute.sdPlugin` в `%APPDATA%\HotSpot\StreamDock\plugins`. Этот путь можно вставить в адресную строку Проводника. [Руководство Stream Dock SDK](https://sdk.key123.vip/en/guide/get-started.html)
3. Открой Control Deck и перетащи **Звук Windows → Микрофон Windows** на нужную кнопку D6.
4. Открой `mmsys.cpl` и перейди в **Запись → Свойства микрофона → Уровни**. Нажми кнопку D6 дважды и проверь смену мута в Windows и индикации на панели.

## Сборка

Запусти из корня репозитория.

```powershell
powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File .\build.ps1
```

Скрипт использует компилятор .NET Framework из Windows. Папка `.sdPlugin` и ZIP для установки появятся в `dist`.
